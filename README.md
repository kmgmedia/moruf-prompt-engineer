# Moruf Prompt Engineer Portfolio

This repository contains the source code for Moruf Adebola's prompt engineering portfolio site.

## Local development

Requirements: Node.js 18+ and npm.

```sh
git clone <YOUR_GIT_URL>
cd moruf-prompt-engineer-portfolio-main
npm install
npm run dev
```

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Build

```sh
npm run build
```

Deploy the generated `dist/` output with your preferred hosting provider.
